# 工作流与本地配套服务

本次范围是桌面客户端及本地配套服务，依据 Codex 的公开交互组织功能。用户尚未准备服务端仓库与域名，因此不包含托管云平台或公网部署，也不承诺与 Codex 的私有服务逐项等价。

## 界面入口

「设置 → 工作区扩展」提供记忆、插件、后台任务和浏览器的集中入口。

- 会话头部的「本地 / Worktree」：选择项目已挂载的目录、创建隔离分支、交接改动、清理干净的 Worktree。
- 输入框底部的「执行 / 计划」：计划模式只允许调查类工具，计划以内嵌步骤卡展示；可设定持续目标。目标状态与中断恢复位于输入框上方。
- 会话头部的「审查」：在右栏查看 PR、差异、评论与失败 CI，向 Agent 附加问题，创建 PR 或发布审查。
- 左侧时钟图标：独立后台任务、待批准操作、主机与手机配对设置。
- 左侧插件图标：插件安装、更新、卸载与 HTTP MCP 账号连接。
- 输入 `/memories`：管理长期记忆及当前会话的使用、贡献设置。
- 输入 `/browser`：浏览器预览与已授权标签页；也可通过命令菜单进入。
- 输入框麦克风：录音听写、连续分段与系统语音播报；波形按钮：文件转写。
- 右栏文件页：Office 版式预览、文字选区批注及另存编辑副本。

默认石墨主题采用中性灰阶；保留海洋、森林、暖阳主题。右栏按内容打开，可调宽度或最大化。工具过程默认折叠，失败自动展开；审批突出实际命令或写入文件。记忆与插件使用具有键盘焦点约束的设置弹窗。

## 本地后台服务

1. 在客户端配置模型、缓存目录和项目。
2. 打开「后台任务 → 主机与设备」，点击「启动本地服务」。当前模型凭据仅同步到服务进程内存，任务日志中不保存模型密钥。
3. 新建任务，选择项目，写明目标和验收条件。每次命令执行或文件写入均须单独批准。
4. 客户端退出后，该服务继续运行。主机进程重启后，重新同步模型与项目，检查中断任务，再明确继续。

安装包包含 Node.js 运行时；从源码单独启动服务需要 Node.js 22 或更新版本：

```sh
node companion/server.mjs --directory /absolute/path/to/host-data
```

普通会话内的持续目标由客户端驱动，客户端重启后暂停等待检查。需要退出客户端后继续的工作，应创建独立后台任务。中断恢复会要求先检查已生效的副作用，不重复沿用旧审批。

本地 Docker 任务使用项目当前已提交版本的独立 Git 克隆，未提交文件不自动复制。先安装并启动 Docker，再通过主机高级选项准备 `octopuses-runner:local` 镜像。命令默认隔离网络，任务创建时可明确允许联网。

## 手机与远程主机

- 本机服务默认仅监听 `127.0.0.1`。
- 手机访问：启动前选中「允许局域网设备访问」，用可信局域网 IP 替换显示地址中的 `127.0.0.1`，打开手机页面，输入一次性配对码。每个设备单独生成，5 分钟过期。
- 客户端可配对另一台主机；远程地址要求 HTTPS，SSH 转发到本机端口时允许 HTTP。公网 TLS、反向代理与服务托管由后续部署提供。
- 服务重启后需要桌面端重新同步凭据。设备配对可统一撤销。

## 浏览器

新网页通过独立预览窗口打开，选中文字后可引用到当前会话。

使用 Chrome / Edge 既有登录标签页时，打开扩展目录，在扩展管理页加载 `browser-extension`，通过一次性配对码连接本地服务，再对具体网站授权。Agent 的 `browser_live` 工具可以读取页面、点击、输入或导航；写操作仍通过审批。扩展权限不会赋予后台任务配置权限。

## 插件与账号连接

当前插件清单包含 Skills 的完整 `SKILL.md` 内容及 MCP 声明。支持 HTTPS 清单或市场索引、安装前预览、更新和卸载；不会执行安装脚本，拒绝覆盖不属于插件或已被用户修改的资源。新 MCP 默认停用，需启用并绑定项目。

这是一套本项目的清单协议，不等同于完整兼容 Codex 的全部插件包、hooks 或二进制资产。远程 MCP 支持 Streamable HTTP、JSON/SSE、会话、工具分页和 OAuth PKCE；具体服务需支持公开客户端动态注册，或提供已注册的 Client ID。令牌保存在系统凭据库。

## 能力与依赖边界

| 能力 | 本地实现 | 所需条件或差异 |
| --- | --- | --- |
| 计划与目标 | 工具状态、验收证据、运行预算、暂停/继续 | 普通会话目标需要客户端运行 |
| 恢复与后台执行 | 原子请求日志、保留附件、独立 Agent 服务 | 服务重启后需重新同步凭据与显式恢复 |
| PR / CI | PR、检查、diff、失败日志、行内评论、发布与审查 | 已安装并登录 GitHub CLI；受账号仓库权限约束 |
| Worktree / Handoff | 隔离分支、目录选择、保留源的改动交接 | 同一 Git 仓库，目标目录干净 |
| 插件与 OAuth | 清单安装更新、远程 MCP、PKCE、系统凭据库 | 兼容性边界见上节 |
| 长期记忆 | 可编辑条目、项目隔离、会话使用/贡献控制、可选提炼 | 默认关闭；自动提炼调用当前模型 |
| 语音 | 麦克风、8 秒独立片段、TTS、语音活动打断 | 需音频转写模型与系统权限；不是原生低延迟流式语音 |
| 浏览器 | 安全预览窗口、选区、已授权登录标签页 | 已有标签页操作需要配套扩展与网站授权 |
| 跨平台 | Linux bwrap / X11 / systemd；Windows Docker / PowerShell / Task Scheduler | Linux Wayland 不支持输入控制；Windows 命令隔离使用 Linux 容器 |
| 远程与容器 | 配对协议、手机界面、本地 Docker 任务 | 本次没有托管云平台、公网 TLS 或域名部署 |
| 多目录项目 | 挂载多个根目录，逐次执行校验所选目录 | Worktree 运行仍以隔离目录优先 |
| Office | PDF 版式、文字选区、批注、DOCX/PPTX 文本与 XLSX 值/公式编辑 | 版式转换需要 LibreOffice；编辑保存新副本，不覆盖原文件 |
