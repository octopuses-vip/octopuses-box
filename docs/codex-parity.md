# 工作流与本地配套服务

本次范围是桌面客户端及本地配套服务，依据 Codex 的公开交互组织功能。用户尚未准备服务端仓库与域名，因此不包含托管云平台或公网部署，也不承诺与 Codex 的私有服务逐项等价。

## 界面入口

「设置 → 工作区扩展」提供记忆和浏览器入口。

- 会话头部的「本地 / Worktree」：选择项目已挂载的目录、创建隔离分支、交接改动、清理干净的 Worktree。
- 输入框底部的「执行 / 计划」：计划模式只允许调查类工具，计划以内嵌步骤卡展示；可设定持续目标。目标状态与中断恢复位于输入框上方。
- 会话头部的「审查」：在右栏查看 PR、差异、评论与失败 CI，向 Agent 附加问题，创建 PR 或发布审查。
- 侧栏的「MCP」可配置本地或远程 MCP 服务，「技能」可管理已保存的技能。
- 输入 `/memories`：管理长期记忆及当前会话的使用、贡献设置。
- 输入 `/browser`：浏览器预览与已授权标签页；也可通过命令菜单进入。
- 输入框麦克风：录音听写、连续分段与系统语音播报；波形按钮：文件转写。
- 右栏文件页：Office 版式预览、文字选区批注及另存编辑副本。

默认石墨主题采用冷灰底色与钴蓝强调。右栏按内容打开，可调宽度或最大化。工具过程默认折叠，失败自动展开；审批突出实际命令或写入文件。记忆使用具有键盘焦点约束的设置弹窗。

## 本机连接服务

安装包包含本机浏览器连接服务及 Node.js 运行时，按需要启动。服务只监听本机回环地址。

旧版独立后台任务与手机控制已移除。旧服务通过应用认证后停止，历史任务文件与工作目录保留。普通会话的持续目标、恢复、SSH 和自动化定时仍可使用。

Windows 用户可在「设置 → 权限与安全」准备 Docker 隔离镜像，供普通会话命令使用。

## 浏览器

新网页通过独立预览窗口打开，选中文字后可引用到当前会话。

使用 Chrome / Edge 既有登录标签页时，在右侧浏览器面板打开扩展目录并生成配对码。加载扩展后，在扩展弹窗填入本机地址与配对码，再对具体网站授权。配对码五分钟内有效、只能使用一次，可在同一面板解除配对。Agent 的 `browser_live` 工具可以读取页面、点击、输入或导航；写操作仍通过审批。

## MCP 与技能

远程 MCP 支持 Streamable HTTP、JSON/SSE、会话和工具分页。插件安装和新的账号授权已移除。此前安装的技能和 MCP 配置可继续从各自的页面管理，远程 MCP 仍可读取和刷新系统凭据库中已保存的授权。

## 能力与依赖边界

| 能力 | 本地实现 | 所需条件或差异 |
| --- | --- | --- |
| 计划与目标 | 工具状态、验收证据、运行预算、暂停/继续 | 普通会话目标需要客户端运行 |
| 会话恢复 | 原子请求日志、保留附件 | 重启后可检查并继续 |
| PR / CI | PR、检查、diff、失败日志、行内评论、发布与审查 | 「审查 → GitHub 连接」可单独检查 GitHub CLI 与账号，读写 PR 需选择有权限的仓库 |
| Worktree / Handoff | 隔离分支、目录选择、保留源的改动交接 | 同一 Git 仓库，目标目录干净 |
| MCP | 本地进程或远程 HTTP，远程服务支持 JSON/SSE 和工具分页 | 需配置并启用服务 |
| 长期记忆 | 可编辑条目、项目隔离、会话使用/贡献控制、可选提炼 | 默认关闭；自动提炼调用当前模型 |
| 语音 | 麦克风、8 秒独立片段、TTS、语音活动打断 | 需音频转写模型与系统权限；不是原生低延迟流式语音 |
| 浏览器 | 安全预览窗口、选区、已授权登录标签页 | 已有标签页操作需要配套扩展与网站授权 |
| 跨平台 | Linux bwrap / X11 / systemd；Windows Docker / PowerShell / Task Scheduler | Linux Wayland 不支持输入控制；Windows 命令隔离使用 Linux 容器 |
| 多目录项目 | 挂载多个根目录，逐次执行校验所选目录 | Worktree 运行仍以隔离目录优先 |
| Office | PDF 版式、文字选区、批注、DOCX/PPTX 文本与 XLSX 值/公式编辑 | 版式转换需要 LibreOffice；编辑保存新副本，不覆盖原文件 |
